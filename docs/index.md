# COBS Code

Python tools for building and analyzing patient-specific finite element models of the pelvic floor.

## Overview

This project uses Python to generate patient-specific FEA models of the pelvic floor, [FEBio](https://febio.org/) to run the simulations, and Python to post-process and analyze the results.

## Status

Early development — code and documentation are being built out incrementally. Check back soon, or visit the [source repository](https://github.com/COBS-Computer/COBS-Code).
